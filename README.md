# סינתטיקו חולון

אפליקציית ניהול קבוצת כדורגל - סגל שחקנים, מחזורים, תוצאות ותשלומים.

## דרישות מקדימות

- [Node.js](https://nodejs.org) - גרסה 18 ומעלה

## הפעלה

פתח טרמינל בתיקייה והרץ:

```
npm install
```

ואחר כך:

```
npm run dev
```

פתח בדפדפן: **http://localhost:3007**

## הערות

- הנתונים נשמרים במחשב שלך באופן מקומי (localStorage)
- אין צורך בחיבור לאינטרנט לאחר ההתקנה
- לגיבוי הנתונים השתמש בדף "גיבוי ושחזור" באפליקציה
