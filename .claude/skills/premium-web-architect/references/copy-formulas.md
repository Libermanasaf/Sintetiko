# Copy Formulas — Headlines, Subheads, CTAs by Niche

Every headline is testable. Every claim is specific. No fluff, no filler.

---

## HEADLINE FORMULAS

### Formula 1: Outcome + Timeframe + Differentiator
`[Result the client wants] ב[timeframe] — [what makes this different]`

Examples:
- קליניקת שיניים: "שיניים לבנות ב-3 ביקורים — ללא כאב, ללא המתנה"
- קבלן: "חידוש מטבח מלא ב-14 יום — עם אחריות 5 שנים"
- SaaS: "חסוך 8 שעות עבודה בשבוע — מהיום הראשון"

### Formula 2: Proof Signal + Action
`[מספר] [יחידה רלוונטית] — [CTA]`

Examples:
- "1,400 לקוחות מרוצים בתל אביב — צור קשר עכשיו"
- "97% הצלחה בבוררויות — ייעוץ ראשוני חינם"
- "43 פרויקטים הושלמו השנה — קבל הצעת מחיר"

### Formula 3: Problem Acknowledgment + Relief
`אתה [מרגיש/חווה X] — אנחנו מטפלים ב[X] ב[timeframe/method]`

Examples:
- "אתה חושש מטיפול שורש — הרדמה ממוחשבת שלנו הופכת אותו לחוויה שגרתית"
- "הדוחות שלך לוקחים שעות — המערכת שלנו מייצרת אותם תוך דקות"

### Formula 4: Specific Local Authority
`[שירות] ב[עיר] — [ייחוד מקומי ספציפי]`

Examples:
- "משרד עו״ד בחיפה — הניסיון המקומי שחשוב לך"
- "אינסטלטור בפתח תקווה — זמינות של 24 שעות, מחיר שקוף"

## SUBHEADING FORMULAS

After the hero headline, the subhead does one job: remove the biggest objection.

### Pattern: Address the #1 Doubt
Identify the main reason a visitor would leave without converting, and neutralize it.

- Clinic: "כל הטיפולים מבוצעים על ידי רופאים מוסמכים בלבד — לא סטודנטים, לא התנסויות"
- SaaS: "התקנה ב-5 דקות, ללא כרטיס אשראי, ביטול בכל עת"
- Contractor: "הצעת מחיר מפורטת בכתב לפני כל עבודה — ללא הפתעות"
- Legal: "ייעוץ ראשוני ללא עלות וללא מחויבות — נדע יחד אם יש לך תיק"

## CTA FORMULAS

### Primary CTA — One Action, Outcome-Focused

| Weak | Strong |
|---|---|
| "שלח" | "שלח ואחזור אליך תוך שעה" |
| "צור קשר" | "קבע שיחה חינם" |
| "הירשם" | "התחל 14 ימי ניסיון חינם" |
| "קבל מידע" | "קבל הצעת מחיר מותאמת" |
| "לחץ כאן" | "ראה דוגמאות עבודה" |

### Secondary CTA — Soft Option (Max 30% Visual Weight)
Always pair a high-commitment CTA with a low-commitment alternative:
- Primary: "קבע תור עכשיו" → Secondary: "שאל שאלה בוואטסאפ"
- Primary: "הורד בחינם" → Secondary: "ראה הדגמה חיה"
- Primary: "קנה עכשיו" → Secondary: "השאר לי ב-wishlist"

## SECTION-SPECIFIC COPY PATTERNS

### Why Us Section
Never: "אנחנו מקצועיים ואמינים"
Always: 3–4 specific, verifiable differentiators with icons.

Template:
```
✓ [מספר] שנות ניסיון ב[תחום]
✓ [מספר] לקוחות שירתנו מאז [שנה]
✓ [תעודה/הסמכה ספציפית] — מספר [מס׳ רישיון]
✓ [ייחוד פרקטי]: [פירוט קצר]
```

### FAQ Copy Rules
Questions should sound like a real person asked them, not marketing copy.

Bad FAQ question: "מה היתרונות של שירותי?"
Good FAQ question: "כמה זה עולה בערך?" / "כמה זמן לוקח הטיפול?" / "האם זה כואב?"

Answers: Direct and complete. If the answer is "it depends," give the range and the factors.

### Testimonial Format
When real testimonials exist:
```
"[ציטוט ספציפי — תוצאה שהושגה, לא סתם 'מדהים']"
— [שם פרטי + ראשי תיבות של שם משפחה], [עיר] · [שירות שקיבל]
```

When no testimonials exist: remove the section entirely. Use a placeholder in the handoff doc: `[יש להוסיף 3 ביקורות אמיתיות לפני השקה]`

### Footer Copy
- Tagline: Repeat the primary positioning statement (not "all rights reserved")
- Legal: "© [שנה] [שם העסק] · מס׳ ח״פ [XXXXXXXXX] · [כתובת מלאה]"
- Accessibility link: "הצהרת נגישות" → `/accessibility`
- Privacy: "מדיניות פרטיות" → `/privacy`

## THINGS NEVER TO WRITE

The following phrases automatically fail the copy review:

Hebrew forbidden phrases:
- "ספק מוביל" / "חברה מובילה"
- "פתרונות מקיפים"
- "איכות ללא פשרות"
- "אנחנו נלהבים"
- "הצוות המקצועי שלנו"
- "שירות ברמה גבוהה"
- "אנחנו כאן בשבילך"
- "כי אתה מגיע לטוב ביותר"

English forbidden phrases (if writing EN):
- "leading provider"
- "comprehensive solutions"
- "we are passionate"
- "world-class"
- "cutting-edge" / "state-of-the-art"
- "synergy" / "leverage" / "paradigm"
- "one-stop shop"

Each of these phrases means nothing because every competitor says the same thing. Replace with specific, measurable, and verifiable claims.
